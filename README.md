# 強奪高校野球

特訓し、強奪し、地方大会から全国大会までを勝ち上がる高校野球の育成シミュレーション。
勝てば相手の主力を1人もらえ、負ければこちらの主力を持っていかれます。
**部屋**（baseball.roomhaird.com）の3つ目として、`/highschool/` に置く予定のものです。

このリポジトリは**本番に入れる前の置き場**です。本番と同じ並びでファイルを置いてあるので、
ここを開けばそのまま試遊できます。

## 試遊のしかた

ビルドは要りません。**ただの HTML と JavaScript** です。

```bash
npx http-server -p 8765 -c-1 .
# → http://127.0.0.1:8765/highschool/
```

`file://` で直接開いても動きますが、ブラウザによっては
保存（localStorage）や書体の読み込みが止まることがあるので、
上のように簡単なサーバーを立てるほうが確実です。

Cloudflare Workers に単体で上げて、スマートフォンから触ることもできます
（`wrangler.jsonc` を同梱してあります。本番に移したら捨ててかまいません）。

```bash
npx wrangler deploy
```

### 見ておきたいところ

- **チーム作り** … チームを5つ並べ、クリックしなくても能力が一覧で見える／**3年生から順**に並ぶ／
  選手をタップすると詳細（守備適性・弾道・打球方向・高校通算成績）が出る
- **特訓** … 「選択」5回で終わり。「見送る」は3回まで、使い切るとボタンが灰色になる。
  カードには対象選手の**打順と守備位置（控えなら「控え」、投手は「先発」「2番手」）**と
  **いまの能力を全部（評価と数字、色付き）**並べたうえで、そのうち**どれがいくつ上がるか**を
  光らせて見せるので、伸ばす価値があるかその場で判断できる。
  見送りを使い切るとボタンは灰色になり、文言も「**見送れません**」に変わる。
  **1人だけのカードは1割**で、1枚あたり平均4.5人。野手全員に効くカードも出る
- **試合** … 送りバントもスクイズも出る。1打席ずつ結果が出て、スコアボードの下で**速さを切り替え**られる
  （**1打席ずつ／通常／2倍／3倍**、初期値は通常。1打席ずつのときは画面をタップすると1つ進む）。
  両チームのオーダーは狭い画面でも**横に2つ並べ**、**その試合の打席結果を全部**並べる。
  グラウンドの絵に**打球が飛ぶ**（中安ならセンター前、右二なら右中間）。
  スコアボードは攻撃中の回を空欄にし、点が入ったらその数字、回が終わってはじめて0を入れる。
  右下に小さく**スキップ**。10回以降はタイブレーク（無死一二塁）。**決勝はコールドなし**
- **試合後** … **勝敗の画面 →（「成長画面」のボタン）→ 試合後の成長 → 試合結果**の順。成長の画面では
  「どれだけ上がったか」と「上がった結果いくつになったか（評価と数字）」が出る
- **試合結果** … スコアボード／**打席結果**／打撃・投球成績
  （名前を押すと通算成績）／両チームの能力一覧／大会の1試合平均得点・失点。
  **打席結果**は表になっていて、1列目が打順、2列目が守備位置の略称、
  3列目から1回・2回…と**その試合で実際に行われた回のぶんだけ**並びます
  （コールドなら7回まで、延長なら延長の回まで）。
  その回に打席が回らなかった選手はそこが空欄になります。選手名は左に固定して出します。
  試合前は**相手のチーム力（数字）は出さない**ので、相手のオーダーと能力を見て自分で見積もる
- **引き抜き** … 勝てば相手から1人取れる。選手を選んでから
  **「引き抜いて次の試合へ」／「引き抜かず次の試合へ」**。放出する部員を選ぶ画面では、
  その選手が**いまオーダーのどこにいるか**（打順・守備位置・控え）が出る。
  そのあと**次の対戦相手を知らせる画面**を挟んでから試合前の画面へ。
  負けると設定しだいで一番良い選手を取られる
- **オフシーズン** … （引き抜かれていれば）取られた選手の**学年・能力・通算成績**→
  3年生の通算成績・能力・活躍シーントップ3（**名前を押せば能力の詳細**）→ 進級 → 新入生を選ぶ
- **設定（右上の「⚙ 設定」）** … 歯車だけだと何のボタンか分からないので、**言葉も一緒に**出しています。
  中は「**名前**（全国大会の名前・自分の高校の名前）」「**遊び方**（負けたときの強奪の有無）」
  「**やり直し**」の3つに分けてあり、それぞれ何が起きるかを添えてあります。
  全国大会の名前の初期値は「乙大人園」

### 進行の保存

進行はブラウザの localStorage に入ります（鍵は `hsbaseball.save`）。
途中で閉じてもトップの「**続きから**」で戻れます。
ゲームの途中でヘッダーの表題を押してトップに戻ったときも、
保存があるかぎり「続きから」が出るので、そこまでの代に戻れます。
最初からやり直すときは、設定画面のいちばん下のボタンから。

## ゲームの流れ

```
チーム作り
  ↓
特訓
  ↓
地方大会 →（優勝）→ 乙大人園 → オフシーズン → 特訓 → 地方大会 → …
  ↓（敗退）                        ↑
  └────────────────────────────────┘
```

### 大会を勝ち上がる間に、選手が化ける

このゲームの軸は**1つの大会の中での成長**です。
**1回戦をF・E・Dで戦ったチームが、準決勝・決勝の頃にはC・B・Aを混ぜられる**ようにしてあります。
そのために4つを同時に動かしています。

1. **入部したての部員は弱い**（`js/player.js` の `GRADE_BASE`）
2. **地方大会の入り口の相手も弱い**（`CONFIG.FIELD.local.from` = 14）
3. **1試合の伸びを大きく取ってある**（`CONFIG.GROWTH`）
4. **1回戦→2回戦→3回戦と、相手の上がり方を大きくしてある**（決勝は70）

#### 何割がどの評価になるか

決め打ちで「決勝ではA が○人」としているのではなく、
上の4つの結果としてこうなる、という形です。
1年目のチームで400回まわし、**その回に臨む時点の**スタメン野手の能力を数えたものです
（ミート・パワー・走力・肩力・守備・捕球の6つ×9人ぶん）。

| 回 | 相手lv | 自軍の平均 | S | A | B | C | D | E | F | G | 突破率 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1回戦 | 14 | 40 | 0% | 0% | 2% | 5% | 14% | 26% | 49% | 3% | 94% |
| 2回戦 | 22 | 44 | 0% | 0% | 3% | 10% | 21% | 27% | 36% | 2% | 89% |
| 3回戦 | 31 | 48 | 0% | 1% | 5% | 16% | 26% | 25% | 27% | 1% | 84% |
| 4回戦 | 39 | 52 | 0% | 1% | 9% | 22% | 27% | 22% | 18% | 1% | 78% |
| 準々決勝 | 48 | 53 | 0% | 2% | 10% | 23% | 27% | 21% | 16% | 0% | 55% |
| 準決勝 | 59 | 57 | 0% | 3% | 15% | 28% | 27% | 17% | 11% | 0% | 33% |
| 決勝 | 70 | 60 | 0% | 5% | 23% | 28% | 23% | 12% | 8% | 0% | 29% |

1回戦は**F・E・Dで89%**。決勝では**C以上が56%**、Aも20人に1人は出ます。
Sは1年目ではまず出ません（学年をまたいで伸ばした先にあります）。
相手は14から70まで、**1回戦ごとにおよそ+8〜+11**で上がっていきます。

1年目に地方大会を勝ち切れるのは**3.3%**です。1年目は勝てなくて当たり前で、
3年かけて積み上げる形にしてあります。

#### 伸び幅の決め方

`CONFIG.GROWTH` にまとめてあります。

| | |
|---|---|
| `PER_STAT` 5.8 | 1つの能力に配る量の係数。上げると全体が速く伸びる |
| `HEAD_SPAN` 62 / `HEAD_CURVE` 1.45 | 頭打ち。100からの残りを62で割って1.45乗する |
| `BENCH` 0.22 | 出番の無かった選手の取り分 |
| `VELO_CHANCE` 0.45 | 投げた試合で球速が上がる確率 |

1試合で動かす能力の数は、その試合の出来しだいで**3〜5個**（控えは2個）です。
活躍した日はまとめて伸びるので、**1試合で化けた**ように見えます。

頭打ちが効くので、同じ伸び方をしてもだんだん鈍ります。

| いまの能力 | 40 | 55 | 70 | 80 | 90 |
|---|---|---|---|---|---|
| 伸びの通りやすさ | 0.94 | 0.66 | 0.40 | 0.20 | 0.07 |

これが無いと、1つの大会で全員がSになってしまいます。

### 能力・成績と勝敗のつながり

**相手の強さは自軍に合わせて動かしません。** 大会に出てくる高校の強さは
`js/config.js` の `CONFIG.FIELD` に固定値で置いてあり（地方大会は1回戦14→決勝70、
全国大会はそこから84まで）、年ごとに±10%ゆれるだけです。
チームを鍛えたぶんだけ、素直に勝てるようになります。

| 大会前のチーム力 | 地方大会 優勝 | 全国大会 優勝 |
|---|---|---|
| 40〜44 | 5% | 0.0% |
| 45〜49 | 7% | 0.0% |
| 50〜54 | 22% | 0.8% |
| 55〜59 | 27% | 2.2% |
| 60〜64 | 40% | 8.6% |
| 65〜69 | 48% | 13% |

（20年×26周＝520年ぶんを回した結果。全体では地方優勝が年28%、全国優勝が年3.8%）

大会の中で大きく伸びるようになったぶん、**大会に入る前のチーム力**だけでは
結果が決まりきらなくなっています。それでも並びは崩れていません
（5% → 7% → 22% → 27% → 40% → 48%）。
特訓でどこまで積んでから大会に入るかが、そのまま勝ち上がれる回数に出ます。

**どこにも0%はありません。**力が足りなくても、次の2つでまれに番狂わせが起きます。

- **その日の調子**（`js/sim.js` の `rollForm`）… 20試合に1回ほど、打線が大きく振れる日がある。
  lv40のチームがlv60の相手に勝つ確率が4%、lv70でも1%弱ある
- **年ごとの顔ぶれ**（`CONFIG.FIELD.oddYear`）… 8%の年は顔ぶれが大きく変わる。
  半分は「戦国の年」、半分は「手薄な年」。手薄な年に当たれば、
  まだ力の足りないチームにも勝ち上がる目が出る

勝てば試合数が増え、試合数が増えれば選手が伸びるので、
一度波に乗ると強い代がしばらく続きます。逆に主力を引き抜かれた年は落ち込みます。

さらに「能力の割に勝てない」「成績の割に打たない」が起きないように、次の3つを揃えてあります。

- **高校通算成績は、試合とまったく同じ計算で作っている**（`sim.js` の `careerBat` /
  `careerPit`）。別の式で作ると、通算打率と大会での打率が食い違う。
  相手は「その選手が実際にぶつかるくらいの高校」を想定している
- **総合力（`Player.rating`）の重みを、試合での効き目に合わせてある**。
  打者はミートとパワーがほとんどで、守備・肩・走力はそれより小さい
- **チーム力（`Team.strength`）は先発投手を重く見る**。1試合で投げるのはほぼ先発1人なので、
  控え投手を同じ重みで混ぜると実際の強さとずれる

いまの設定では、画面に出ている**チーム力の差と勝率**がこのくらいになります。

| チーム力の差 | −15 | −10 | −5 | ±0 | +5 | +10 | +15 |
|---|---|---|---|---|---|---|---|
| 勝率 | 8% | 16% | 32% | 48% | 70% | 87% | 97% |

### 特訓カードの引き方

「**何の練習か**」「**何人に効くか**」「**どれだけ効くか**」を、それぞれ別に引いています
（`js/training.js` の `MENUS` / `COUNT_TIERS` / `POWER_TIERS`）。
人数と効き目が独立なので、**全体練習の猛特訓**のような当たりがまれに出ます。

| 人数 | 1人 10% ／ 2人 18% ／ 3人 20% ／ 4〜5人 22% ／ 6〜8人 18% ／ 全員 12% |
|---|---|
| **効き目** | ふつう 70%（+3〜9） ／ みっちり 22%（+10〜17） ／ **猛特訓 8%（+20〜32）** |

7人以上と猛特訓が重なるのは **2%**。

試合1つの伸びが大きいゲームなので、特訓の幅もそれに合わせて広げてあります。
ここが小さいままだと、年に1度しか来ない特訓が誤差になってしまいます。
球速と変化球だけは上限（168km/h・切れ味7）がすぐそこにあるので、幅を広げていません。

### 現実の高校野球に寄せているところ

- **送りバントとスクイズ**（`js/sim.js` の `chooseTactic`）。走者が出たら送る、が高校野球の基本形なので、
  2番打者と下位打線、終盤の接戦ほど出しやすい。**犠打は1チーム1試合あたり0.8〜1.2**。
  強い学校ほど送らない、ではなく、打順の決まりごとのほうを強くしてある
- **球速はひとつながりの分布**から引いている。「何割が150km/h」という決め打ちはしていない。
  中心は学年とチームの強さで動き、そこに才能とばらつきが乗るだけなので、
  148km/hも149km/hもそれぞれの確率で出る

  | 3年生の投手 | 145以上 | 148以上 | 150以上 | 155以上 |
  |---|---|---|---|---|
  | 強豪校（lv60） | 21% | 13% | 8.6% | 2.7% |
  | 弱小校（lv20） | 2.4% | 1.1% | 0.6% | 0.1% |

  弱い学校にも、200人に1人くらいは150km/hが紛れている
- **同じ学校の中の力の差が大きい**。エース級が1人いても、他は並という形が出る
- **コールドゲーム**は5回10点差・7回7点差。**地方大会の決勝と全国大会は行わない**（現実の全国大会と同じ）
- **その日の出来**。チームにも選手にも、試合ごとの調子がある。10人に1人くらいは大きく振れる
- **背番号**はエースが1、捕手が2、内野3〜6、外野7〜9、指名打者10、控え投手が11から

### 投手の疲れ

投手は投げるほど疲れが溜まり、球威と制球が落ちます（`js/team.js` の `restPitchers`）。

- 1試合で「アウト1つにつき +1.4」溜まり、登板した日は −6、**まったく投げなかった日は −34**
- 完投するとおよそ +32。連投を重ねると終盤で崩れるので、継投を考える必要がある
- オフシーズンで抜けきる

オーダー変更の投手一覧と、選手の詳細に「万全／軽い疲れ／やや疲労／疲労大」で出ます。

### 引退とドラフト

3年生のうち、能力と大会での活躍が飛び抜けた選手はプロへ行きます
（`js/offseason.js` の `draftPick`）。オフシーズンの引退の欄に
**ドラフト1位〜育成ドラフト**として出ます。1年目のチームではまず出ません。

### オーダー変更

上に**「打線」「投手」のタブ**があり、**一度に出るのはどちらか片方だけ**です。
狭い画面に両方を出すと、どちらも読みづらくなるためです。

「打線」では野手13人を**ひとつづきの並び**で出します。**上から9人がスタメン**、残りが控えです。
行の左はしの取っ手をつまんで上下に動かすと並べ替えられ、
**控えの選手を上に持ち上げれば、そのまま出場します**（だから「交代」のボタンはありません）。

- 守備位置は**選手について回ります**。1人の守備位置を変えても他の選手は動きません
- 重なったときは、**その場では赤くしません**。動かしている途中は一時的に重なるのが当たり前で、
  そのたびに赤くなると落ち着かないからです。**「決定」を押した時点で**重なっていれば、
  そこではじめて警告と薄い赤のハイライトが出て、閉じずに直せます
- 行ごとに**守備適性を8か所ぶん**並べてあるので、どこを守れるかがひと目で分かります
- 選手名を押すと、このふきだしの中で詳細が開きます（×でオーダーに戻ります）
- 左投げの選手は**捕手・二塁・三塁・遊撃には入りません**（適性がGになります）

「投手」のタブでは起用順を並べ替えます。**変化球と疲れ**も一緒に出ます。

- 指でもマウスでも動きます。つまんだ行は浮き上がって指について動き、
  すれ違った行とその場で入れ替わります
- 上や下のはしまで持っていくと、ひとりでにスクロールします
  （これが無いと、いちばん下の控えをいちばん上まで持ち上げられない）
- つまめるのは取っ手だけです。行全体をつまめるようにすると、画面のスクロールができなくなります
- ▲▼のボタンと「おまかせ」も残してあります

#### 「おまかせ」の守備位置の決め方

守備位置は**割り当て問題**として解いています（`js/team.js` の `bestAssign`、ハンガリー法）。

上から順に空いている位置へ埋めていく単純なやり方だと、
**遊撃が得意な選手が左翼に、左翼が得意な選手が遊撃に**入ってしまうことがあります
（先に来た選手が良い位置を取ってしまうため）。
8人×8か所の組み合わせを全部見て**合計がいちばん良くなる**割り当てを選ぶので、
「入れ替えたほうが両方とも良くなる組」は残りません。

重みは**守備適性が主、総合力は 0.25 の添え物**です。総合力を重くすると、
適性を無視して強い選手が内野の真ん中に寄ってしまいます。

### 一覧の並び替え

部員の一覧は**打順／学年／能力／守備位置**で並び替えられます
（`js/ui.js` の `makeSortable`）。役割（スタメン・控え）ではなく**打順**で並ぶので、
「4番は誰か」を探すときにそのまま上から数えられます。

### 選手の能力

ミート・パワー・走力・肩力・守備・捕球・制球・スタミナは 1〜100 の数字で持ち、
画面では下の評価に直して出します。入部したての部員はF・Gだらけで、
そこから試合を重ねて上げていきます。

| 評価 | S | A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|---|---|
| 数値 | 90〜100 | 80〜89 | 70〜79 | 60〜69 | 50〜59 | 40〜49 | 15〜39 | 1〜14 |
| 色 | 金（塗り） | ピンク | 赤 | オレンジ | 黄 | 緑 | 薄い水色 | 灰 |

色は `css/style.css` の `--r-s` 〜 `--r-g`。紙色の地の上でも読めるよう、
黄と薄い水色だけ少し濃くしてあります。いちばん上のSだけは**金色の塗りつぶし**にして目立たせています。

**守備適性（捕一二三遊左中右のA〜G）だけは色を付けていません。**
能力の評価と同じ色で塗ると、どちらを見ているのか分からなくなるためです。

- **野手** … 学年／右投左投・右打左打／守備適性（捕一二三遊左中右をA〜Gで）／
  弾道（1〜4、大きいほど高い）／ミート・パワー・走力・肩力・守備・捕球／
  引っ張り〜広角（+100に近いほど引っ張り、−100に近いほど流し、0はセンター返し）
- **投手** … 学年／右投左投・右打左打／最速／制球／スタミナ／変化球（球種ごとに1〜7）

左投は右投の半分ほど（投手は8割ほど）の割合で出ます。左投右打はごく稀です。
変化球は現実と同じで、スライダーやカーブはありふれていて、
ナックルを投げる投手はまず出てきません。切れ味は1〜7ですが、
高校生なので**2前後が並**。5以上の決め球を持つ投手はめずらしく、
球威（`Sim.stuffOf`）も球速のほうを重く見ています。
弾道も**1〜2がほとんど**で、4はめったに出ません。

選手名はどこからでも（詳細画面の「名前を変える」から）書き換えられます。

### 相手校

高校名は `js/names.js` にあります。どれも実在の学校とは関係のない架空の高校です。

- **地方大会** … どこの県にもありそうな当たり障りのない名前を、
  地名っぽい言葉（`LOCAL_HEAD`）と学校の種類（`LOCAL_TAIL`）の組み合わせで作る
- **全国大会** … 名前を聞いただけで強そうに感じてほしいので、
  実在の強豪校をもじった名前（`NATIONAL_SCHOOLS`）から選ぶ

同じ高校名が出ないようにしているのは**同じ大会の中だけ**です。
年をまたげば、同じ常連校がまた出てきます。

地方大会は**1回戦ごとにはっきり強くなります**（14 → 22 → 31 → 39 → 48 → 59 → 70）。
自軍も試合ごとに大きく伸びるので、相手の上がり方が緩いと3回戦あたりから消化試合になってしまいます。
**4回戦がある確率は50%**、低い確率で前の相手より弱いところが当たりますが、
準々決勝→準決勝→決勝だけは必ず強くなります。
乙大人園の1回戦は地方大会の決勝と同じくらいの強さから始まり、決勝は84です。

## 広告について

`team/`・`quiz/` と同じ仕組みをそのまま使っています。枠は3か所です。

| id | 場所 |
|---|---|
| `ad-top` | ヘッダーの下（全画面共通） |
| `ad-result` | 試合結果のスコアの下 |
| `ad-footer` | フッターの上（全画面共通） |

中身は本番の `js/ads.js`（`AD_CONFIG`）が決めます。いまは楽天アフィリエイトの
モーションウィジェットと商品リンクが入っていて、`adsense.slots` に
広告ユニットIDを入れれば、同じ枠がそのまま Google の広告に切り替わります
（`js/ads.js` を直すだけで、このゲーム側は触らなくて済みます）。

解答や操作のボタンのすぐ隣には枠を置いていません（誤タップは規約違反になるため）。
広告が1つでも出たときだけ、フッターに「アフィリエイト広告を利用しています」の
一文が出ます。

このリポジトリの `js/ads.js` は本番からのコピーです。試遊のときに枠の位置だけ
確かめたいときは、URL に `?adtest=1` を付けてください。

    ├── rng.js          乱数の道具（正規分布まがい・重み付き抽選）
    ├── names.js        選手名と高校名のもと
    ├── player.js       選手を作る。能力・適性・利き手・変化球・練習試合の通算成績
    ├── team.js         チーム、打順と守備位置の組み立て
    ├── sim.js          試合の計算。1打席ずつ決めて log に並べる。
    │                   練習試合ぶんの通算成績も同じ計算で作る
    ├── tournament.js   相手校とトーナメントの山
    ├── dataset.js      チーム作り・新入生で見せる5つの組
    ├── training.js     特訓（練習カード）
    ├── growth.js       試合後の成長と覚醒、活躍シーン
    ├── offseason.js    引退・進級・入部

`game-screen.js` がそれを1つずつ見せています。
だから「スキップ」は残りをまとめて流すだけで済みます。

## 数字の直し方（難易度・確率）

触りたくなりそうなところだけ。

| したいこと | 場所 |
|---|---|
| 特訓の回数・見送りの上限 | `js/config.js` の `CONFIG.TRAINING` |
| 特訓カードの種類と出やすさ・伸び幅 | `js/training.js` の `draw()`（`kinds` の `weight` が出やすさ） |
| コールドゲームの規定・タイブレーク開始回 | `js/config.js` の `CONFIG.GAME` |
| 変化球の珍しさ | `js/config.js` の `PITCH_TYPES` の `weight` |
| 全国大会の名前の初期値 | `js/config.js` の `CONFIG.DEFAULTS.nationalName`（画面からも変えられます） |
| **相手の強さ（難易度そのもの）** | `js/config.js` の `CONFIG.FIELD`。`local.from` が1回戦、`local.to` が決勝、<br>`national.to` が全国決勝のめやす。**小さくすると易しく**なります |
| 勝ち上がるほど強くなる曲がり具合 | `js/tournament.js` の `strengthLadder()`（`Math.pow(t, 1.05)` の指数。<br>1に近いほど一直線に、大きくするほど終盤で急になります） |
| 番狂わせの起きやすさ | `js/sim.js` の `rollForm()`（その日の調子）と `CONFIG.FIELD.oddYear`（年ごとの顔ぶれ） |
| 1〜4回戦の強さ | `js/config.js` の `CONFIG.FIELD.local.from` |
| 守備位置のおまかせ | `js/team.js` の `bestAssign()`（重み `defScore + rating * 0.25`） |
| 打席結果の表 | `js/game-screen.js` の `paLog()` |
| 投手の疲れ方・抜け方 | `js/team.js` の `restPitchers()` |
| ドラフトのかかる線 | `js/offseason.js` の `draftPick()` |
| 能力の評価の色 | `css/style.css` の `--r-s` 〜 `--r-g` |
| 変化球の出やすさ・切れ味 | `js/player.js` の `rollPitches()`。試合での効き目は `js/sim.js` の `stuffOf()` |
| 弾道の出かた | `js/player.js` の `newBatter()` の `traj` |
| 試合の速さ（各段階の待ち時間） | `js/game-screen.js` の `step()` の `wait` |
| 勝ち上がりの強さの上がり方 | `js/tournament.js` の `strengthLadder()` |
| 4回戦がある確率 | `js/tournament.js` の `RNG.chance(0.5)` |
| 覚醒の起きやすさ | `js/growth.js` の `afterGame()` 内、`chance` の式 |
| 試合後の伸び幅 | `js/growth.js` の `gainFor()` と `GRADE_GAIN` |
| 打撃・投球の確率（三振率・四球率・本塁打率など） | `js/sim.js` の `resolvePA()` |
| 新入部員の弱さ | `js/player.js` の `GRADE_BASE`（いまは1年19・2年27・3年33）と `rollTalent()` |
| **1試合の伸び幅（成長の速さそのもの）** | `js/config.js` の `CONFIG.GROWTH`。`PER_STAT` を上げると速く伸び、<br>`HEAD_SPAN` を下げると高いところで頭打ちになります |
| 1回戦ごとの強さの上がり幅 | `js/config.js` の `CONFIG.FIELD.local`（`from` と `to` の差が大きいほど急） |

いまの設定では、チーム力が45前後のうちは地方大会の優勝が**年7%**、
60を超えると**年4割**、全国大会も**年1割**ほど狙えるようになります。
弱いうちは勝てず、鍛えたぶんだけ勝てるようになる形です。

難易度を動かすなら `js/config.js` の `CONFIG.FIELD` です。

| 設定 | 地方優勝（全体） | 全国優勝（全体） |
|---|---|---|
| 11→62 / 78 | 年48% | 年12% |
| 11→70 / 88 | 年29% | 年2.3% |
| **14→70 / 84（いま）** | **年28%** | **年3.8%** |

`from` を上げると、優勝の回数そのものより**序盤で消える年**が増えます。
`to` を上げると、勝ち上がるほど急に苦しくなります。

（数字は「毎回いちばん強い組を選び、勝つたびに相手の主力を引き抜く」
遊び方を回した結果なので、ふつうに遊べばこれより下がります）
