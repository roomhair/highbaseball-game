# 高校野球

部員を集め、特訓し、地方大会から全国大会までを勝ち上がる高校野球の育成シミュレーション。
**部屋**（baseball.roomhaird.com）の3つ目として、`/highschool/` に置く予定のものです。

このリポジトリは**本番に入れる前の置き場**です。本番と同じ並びでファイルを置いてあるので、
ここを開けばそのまま試遊できます。

## 試遊のしかた

ビルドは要りません。**ただの HTML と JavaScript** です。

```bash
npx http-server -p 8765 -c-1 .
# → http://127.0.0.1:8765/highschool/
```

`file://` で直接開いても動きますが、ブラウザによっては
保存（localStorage）や書体の読み込みが止まることがあるので、
上のように簡単なサーバーを立てるほうが確実です。

Cloudflare Workers に単体で上げて、スマートフォンから触ることもできます
（`wrangler.jsonc` を同梱してあります。本番に移したら捨ててかまいません）。

```bash
npx wrangler deploy
```

### 見ておきたいところ

- **チーム作り** … チームを5つ並べ、クリックしなくても能力が一覧で見える／
  選手をタップすると詳細（守備適性・弾道・打球方向・高校通算成績）が出る
- **特訓** … 「選択」5回で終わり。「見送る」は3回まで、使い切るとボタンが灰色になる。
  カードには対象選手の**打順と守備位置（控えなら「控え」、投手は「先発」「2番手」）**と
  **いまの能力ひと通り**が出るので、伸ばす価値があるかその場で判断できる
- **試合** … 1打席ずつ結果が出る。スコアボードの下で**速さを切り替え**られる
  （**1打席ずつ／通常／2倍／3倍**、初期値は通常。1打席ずつのときは画面をタップすると1つ進む）。
  右下に小さく**スキップ**。10回以降はタイブレーク（無死一二塁）
- **試合結果** … スコアボード／打撃・投球成績（名前を押すと通算成績）／両チームの能力一覧／
  大会の1試合平均得点・失点。試合前は**相手のチーム力（数字）は出さない**ので、
  相手のオーダーと能力を見て自分で見積もる
- **引き抜き** … 勝てば相手から1人取れる（同じ区分の部員を1人放出）。
  負けると設定しだいで一番良い選手を取られる
- **オフシーズン** … （引き抜かれていれば）取られた選手の**学年・能力・通算成績**→
  3年生の通算成績・能力・活躍シーントップ3 → 進級 → 新入生を選ぶ
- **設定（右上の⚙）** … **全国大会の名前**と自校名を変えられる。初期値は「乙大人園」

### 進行の保存

進行はブラウザの localStorage に入ります（鍵は `hsbaseball.save`）。
途中で閉じてもトップの「続きから」で戻れます。
最初からやり直すときは、設定画面のいちばん下のボタンから。

## ゲームの流れ

```
チーム作り
  ↓
特訓
  ↓
地方大会 →（優勝）→ 乙大人園 → オフシーズン → 特訓 → 地方大会 → …
  ↓（敗退）                        ↑
  └────────────────────────────────┘
```

### 能力・成績と勝敗のつながり

「能力の割に勝てない」「成績の割に打たない」が起きないように、次の3つを揃えてあります。

- **高校通算成績は、試合とまったく同じ計算で作っている**（`sim.js` の `careerBat` /
  `careerPit`）。別の式で作ると、通算打率と大会での打率が食い違う。
  相手は「その選手が実際にぶつかるくらいの高校」を想定している
- **総合力（`Player.rating`）の重みを、試合での効き目に合わせてある**。
  打者はミートとパワーがほとんどで、守備・肩・走力はそれより小さい
- **チーム力（`Team.strength`）は先発投手を重く見る**。1試合で投げるのはほぼ先発1人なので、
  控え投手を同じ重みで混ぜると実際の強さとずれる

いまの設定では、画面に出ている**チーム力の差と勝率**がこのくらいになります。

| チーム力の差 | −15 | −10 | −5 | ±0 | +5 | +10 | +15 |
|---|---|---|---|---|---|---|---|
| 勝率 | 8% | 16% | 32% | 48% | 70% | 87% | 97% |

### 選手の能力

ミート・パワー・走力・肩力・守備・捕球・制球・スタミナは 1〜100 の数字で持ち、
画面では下の評価に直して出します。

| 評価 | S | A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|---|---|
| 数値 | 90〜100 | 80〜89 | 70〜79 | 60〜69 | 50〜59 | 40〜49 | 15〜39 | 1〜14 |

- **野手** … 学年／右投左投・右打左打／守備適性（捕一二三遊左中右をA〜Gで）／
  弾道（1〜4、大きいほど高い）／ミート・パワー・走力・肩力・守備・捕球／
  引っ張り〜広角（+100に近いほど引っ張り、−100に近いほど流し、0はセンター返し）
- **投手** … 学年／右投左投・右打左打／最速／制球／スタミナ／変化球（球種ごとに1〜7）

左投は右投の半分ほど（投手は8割ほど）の割合で出ます。左投右打はごく稀です。
変化球は現実と同じで、スライダーやカーブはありふれていて、
ナックルを投げる投手はまず出てきません。切れ味は1〜7ですが、
高校生なので**2前後が並**。5以上の決め球を持つ投手はめずらしく、
球威（`Sim.stuffOf`）も球速のほうを重く見ています。
弾道も**1〜2がほとんど**で、4はめったに出ません。

選手名はどこからでも（詳細画面の「名前を変える」から）書き換えられます。

### 相手校

高校名は `js/names.js` にあります。どれも実在の学校とは関係のない架空の高校です。

- **地方大会** … どこの県にもありそうな当たり障りのない名前を、
  地名っぽい言葉（`LOCAL_HEAD`）と学校の種類（`LOCAL_TAIL`）の組み合わせで作る
- **全国大会** … 名前を聞いただけで強そうに感じてほしいので、
  実在の強豪校をもじった名前（`NATIONAL_SCHOOLS`）から選ぶ

同じ高校名が出ないようにしているのは**同じ大会の中だけ**です。
年をまたげば、同じ常連校がまた出てきます。

地方大会は1回戦から徐々に強くなります。**4回戦がある確率は50%**、
低い確率で前の相手より弱いところが当たりますが、
準々決勝→準決勝→決勝だけは必ず強くなります。
乙大人園の1回戦は地方大会の決勝と同じくらいの強さから始まります。

## 本番サイトへの入れ方

本番（`roomhair/baseball-statsquiz`）に移すのは **`highschool/` だけ**です。
このリポジトリの他のファイル（`index.html` / `css/` / `js/` / `fonts/` /
`privacy.html` / `_headers` / `wrangler.jsonc`）は、試遊を本番と同じ形にするための
コピーなので、持っていく必要はありません。

1. `highschool/` を丸ごと `baseball-statsquiz/highschool/` に置く
2. 本番の `index.html` の `<ol class="index">` に、3つ目として下を足す

```html
<li class="index__item">
  <a class="index__link" href="highschool/">
    <span class="index__no">03</span>
    <span class="index__mark" aria-hidden="true">
      <!-- 本塁ベース。小さく出しても形が残るように、線は太めに -->
      <svg viewBox="0 0 32 32" fill="none" stroke="currentColor"
           stroke-width="1.3" stroke-linejoin="round">
        <path d="M8 7h16v11l-8 7-8-7Z"/>
      </svg>
    </span>
    <span class="index__name">高校野球</span>
    <span class="index__desc">部員を集め、特訓し、地方大会からその先へ。3年生は引退し、新入生が入る。負ければ主力を引き抜かれる。</span>
    <span class="index__meta">ひとりで<i>／</i>10〜20分</span>
  </a>
</li>
```

3. 本番の `sitemap.xml` に1行足す

```xml
<url>
  <loc>https://baseball.roomhaird.com/highschool/</loc>
  <changefreq>weekly</changefreq>
  <priority>0.9</priority>
</url>
```

`highschool/index.html` は部屋の共通ファイル（`../js/theme.js`・`../js/ads.js`・
`../../fonts/archivo-var.woff2`）を見ています。本番にはどれも既にあるので、
置くだけで配色の切り替えも広告も書体もつながります。

## 広告について

`team/`・`quiz/` と同じ仕組みをそのまま使っています。枠は3か所です。

| id | 場所 |
|---|---|
| `ad-top` | ヘッダーの下（全画面共通） |
| `ad-result` | 試合結果のスコアの下 |
| `ad-footer` | フッターの上（全画面共通） |

中身は本番の `js/ads.js`（`AD_CONFIG`）が決めます。いまは楽天アフィリエイトの
モーションウィジェットと商品リンクが入っていて、`adsense.slots` に
広告ユニットIDを入れれば、同じ枠がそのまま Google の広告に切り替わります
（`js/ads.js` を直すだけで、このゲーム側は触らなくて済みます）。

解答や操作のボタンのすぐ隣には枠を置いていません（誤タップは規約違反になるため）。
広告が1つでも出たときだけ、フッターに「アフィリエイト広告を利用しています」の
一文が出ます。

このリポジトリの `js/ads.js` は本番からのコピーです。試遊のときに枠の位置だけ
確かめたいときは、URL に `?adtest=1` を付けてください。

## ファイルの置き場所

```
highschool/
├── index.html          画面の骨組み（中身はJSが描く）
├── css/style.css       見た目。色は :root の変数にまとめてある
└── js/
    ├── config.js       定数。評価（S〜G）・守備位置・変化球の一覧・試合の規定
    ├── rng.js          乱数の道具（正規分布まがい・重み付き抽選）
    ├── names.js        選手名と高校名のもと
    ├── player.js       選手を作る。能力・適性・利き手・変化球・練習試合の通算成績
    ├── team.js         チーム、打順と守備位置の組み立て
    ├── sim.js          試合の計算。1打席ずつ決めて log に並べる。
    │                   練習試合ぶんの通算成績も同じ計算で作る
    ├── tournament.js   相手校とトーナメントの山
    ├── dataset.js      チーム作り・新入生で見せる5つの組
    ├── training.js     特訓（練習カード）
    ├── growth.js       試合後の成長と覚醒、活躍シーン
    ├── offseason.js    引退・進級・入部
    ├── storage.js      進行の保存
    ├── ui.js           画面の出し入れ、選手詳細、オーダー編集
    ├── screens.js      試合以外の画面
    ├── game-screen.js  試合中と試合結果の画面
    └── main.js         進行の全体。どの画面の次がどの画面かはここだけ見れば分かる
```

試合の中身は `sim.js` が先に最後まで計算して `log` に並べ、
`game-screen.js` がそれを1つずつ見せています。
だから「スキップ」は残りをまとめて流すだけで済みます。

## 数字の直し方（難易度・確率）

触りたくなりそうなところだけ。

| したいこと | 場所 |
|---|---|
| 特訓の回数・見送りの上限 | `js/config.js` の `CONFIG.TRAINING` |
| コールドゲームの規定・タイブレーク開始回 | `js/config.js` の `CONFIG.GAME` |
| 変化球の珍しさ | `js/config.js` の `PITCH_TYPES` の `weight` |
| 全国大会の名前の初期値 | `js/config.js` の `CONFIG.DEFAULTS.nationalName`（画面からも変えられます） |
| **地方大会の相手の強さ** | `js/main.js` の `startTournament()`。`Team.strength(...) * 0.62` の係数を<br>**小さくすると易しく**、大きくすると難しくなります |
| 変化球の出やすさ・切れ味 | `js/player.js` の `rollPitches()`。試合での効き目は `js/sim.js` の `stuffOf()` |
| 弾道の出かた | `js/player.js` の `newBatter()` の `traj` |
| 試合の速さ（各段階の待ち時間） | `js/game-screen.js` の `step()` の `wait` |
| 勝ち上がりの強さの上がり方 | `js/tournament.js` の `strengthLadder()` |
| 4回戦がある確率 | `js/tournament.js` の `RNG.chance(0.5)` |
| 覚醒の起きやすさ | `js/growth.js` の `afterGame()` 内、`chance` の式 |
| 試合後の伸び幅 | `js/growth.js` の `gainFor()` と `GRADE_GAIN` |
| 打撃・投球の確率（三振率・四球率・本塁打率など） | `js/sim.js` の `resolvePA()` |
| 新入部員の弱さ | `js/player.js` の `GRADE_BASE` と `rollTalent()` |

いまの設定でおおよそ、地方大会の優勝が**年2割弱**、
乙大人園の優勝が**年5〜6%**（出場できた年のうち3割前後）になります。
山場は地方大会で、そこを抜ければ全国はそれなりに戦えます。

難易度を動かすなら、まず `js/main.js` の **`0.62`** です。

| 係数 | 地方優勝 | 全国優勝 |
|---|---|---|
| 0.52 | 年33% | 年15% |
| 0.58 | 年36% | 年15% |
| **0.62（いま）** | **年19%** | **年6%** |

（数字は「毎回いちばん強い組を選び、勝つたびに相手の主力を引き抜く」
遊び方で12年×6周を回した結果なので、ふつうに遊べばこれより下がります）
