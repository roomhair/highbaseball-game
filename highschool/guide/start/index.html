はじめての強奪高校野球｜最初の1年の進め方

強奪高校野球は、最初のチームがとても弱いところから始まります。最初の1年で大切なのは、「勝つこと」よりも「3年かけて強いチームに育てる土台を作ること」です。このページでは、チーム作りから最初の夏の県大会までを、順番に説明します。

ゲームを始める（強奪高校野球）

最初の3年間は、思ったより厳しい

「最初のチームは弱い」と言われても、どれくらい弱いのかは分かりにくいものです。そこで、特訓のカードを完全に運任せで選び、強奪も采配もしない、という最悪に近いやり方で、3年間の夏の県大会を何百回も自動で遊ばせて、結果を数えてみました。

  • 1年目の夏：1回戦で負けることが、3回に1回ほどあります。勝ち進んでも、優勝はほぼ届きません。
  • 2年目の夏：1回戦負けは減って、準々決勝あたりまで進むことが増えます。
  • 3年目の夏：優勝する年が出てきますが、それでも、運任せのままでは、まだ少数です。

何も考えずに遊んでも、年を追うごとに少しずつ強くなります。ここから先は、特訓の選び方・強奪・采配で、どれだけ上積みできるかというゲームだと考えてください。1年目に1回戦で負けるのは、運の悪い人だけの話ではなく、普通に起こることです。

どの候補を選んでも、人数と学年は同じ

最初に選ぶチームの候補は、どれも野手18人・投手8人で、野手は各学年6人ずつ、投手は2人・3人・3人に分かれています。つまり「3年生が多い組」「1年生ばかりの組」といった偏りはありません。違うのは、選手の質と、守備位置の顔ぶれです。選ぶときは、次の順に見てください。

  1. 捕手と遊撃手に、守れる選手がいるか：守備適性(G〜A)が低い位置に置くと、守備力が大きく下がります。捕手・遊撃・中堅は特に厳しいので、ここに適性B以上がいる組を優先します。
  2. 投手に、スタミナと制球が両方そこそこある選手がいるか：球速だけ高くても、中盤で崩れます。理由は投手運用のページで数字つきで説明しています。
  3. 1・2年生に、能力の高い選手がいるか：3年生は夏で引退します。残る選手の質が、2年目以降の土台になります。

時間の流れ：特訓を選ぶたびに月が進む

ゲームは2026年4月から始まり、画面の左上に「◯年◯月」が出ています。特訓は、カードを1枚選ぶたびに月が進みます(見送りでは進みません)。最初の特訓は、4月から夏の県大会がある7月までです。選べる回数にならして、1か月ずつ進みます。

月が変わる前には、「4月の成果」「5月の成果」という画面が出ます。全員の能力が、いくつ上がった(または下がった)かが一覧で分かり、特訓があった月は、その下に「特訓で上がった分」も出ます。日々の成長や毎月の練習で、特訓以外にも少しずつ上がるので、特訓を選んでいない選手の変化も、ここで確かめられます。

オーダーと鍵

オーダーの画面では、選手の名前の横にある鍵のマークを押すと、その選手に鍵が付きます。鍵が付いた選手は、「野手をおまかせ」を押しても、必ずスタメンに入ります。「この選手は必ず使いたい」と決めているときに便利です。スタメンは9人なので、鍵を付けられるのも9人までです。

キャプテンは、長く残る選手を

夏が終わると、3年生が引退して、キャプテンを選び直します。1年目の最初は、1年生か2年生を選んでおくと、選び直しの回数が減ります。ここで悩みすぎる必要はありません。

コールド負けには注意：サッカー部になる

夏と秋の県大会では、大きな点差がつくと、コールドゲームで終わります(決勝と全国大会にはありません)。県大会の1回戦か2回戦で、コールド負けをすると、部員がやる気をなくして、野球部がそのままサッカー部になります。サッカー部としての大会が始まりますが、野球部に戻ることもできます。いきなり強い相手に当たると、事故のように起こるので、最初の試合では、点差が開きそうなら、投手交代や采配で粘ってください。

負けたら、強奪される

夏の県大会・全国大会で負けると、設定によっては、自校でいちばん良い選手を、相手校に強奪されます。そのぶん、翌年の新入生が1人多く入ります。右上の歯車マークの設定から、この強奪を外せるので、最初は外して雰囲気をつかむのも、1つの手です。

2年目に向けて

夏が終わると、3年生が引退して、秋の大会へ進みます。春の大会が終わると、新入生が入部します。新入生の強さは、学校の格(スカウトレベルEからA)で変わり、勝ち上がった回数、全国大会や秋・春の大会への出場、プロに行った卒業生の数で上がっていきます。1年目に1回戦で負けても、その後の積み重ねで、少しずつ新入生が良くなるように作っています。
